# 🤸 onepicard

팔이 고무처럼 늘어나는 해적들이 주인공인, 브라우저에서 AI와 겨루는 팬 카드게임입니다. 여러 작품의 캐릭터 이름을 빌려 쓴 개인용 게임이라 정식으로 공개하지 않습니다.

## 2.0.1에서 바뀐 점

- 시작 화면 오른쪽 위 📢 공지 버튼으로 업데이트 내용을 볼 수 있다(새 버전을 안 봤으면 빨간 점, 대전 중에는 숨김). 튜토리얼·카드 도감·승률·상성 버튼은 시작 화면 오른쪽 위로 옮겼다.
- 📊 승률·상성을 내 전적 · 평균 승률 · 표준편차 · 상성표 탭으로 나눴다. 상성표는 화면 폭에 맞춰 줄어든다.
- 얼음·닻 등으로 턴을 쉰 선원은 그 턴이 끝나면 상태 표시가 풀린다(다음 상대 턴까지 '얼어붙음'으로 남아 고드름 투척 피해와 맞지 않던 문제).
- 공격할 대상을 고를 때 칠 수 있는 카드에는 빨간 테두리와 🎯, 칠 수 없는 카드는 흐리게. 상태 꼬리표는 카드 위 가장자리로.
- 튜토리얼 시작 손패 고정, 📊 승률·상성에 AI 상성 표준편차표 추가.

## 2.0.0에서 바뀐 점

- **해적단별 공격 연출**: 17개 해적단마다 고유 공격 연출(대포, 물대포, 유령 분신, 불칼, 바나나, 태엽 펀치, 참격파, 돌풍, 어뢰, 금화, 얼음 숨결, 과일 비, 돌진, 포자 구름, 와이어 기동, 연성진, 고무 펀치). 공용 카드는 가볍게 돌진. 게임 화면의 ✨ 연출 버튼으로 끌 수 있다.
- **연타**: 맞는 순간에 다음 행동을 받고, 연출 중에도 다음 공격을 미리 골라 두면 이어서 친다.
- **상태 표시**: 공격을 못 하게 된 선원에 원인별 꼬리표(❄ 얼어붙음, ⚓ 닻에 묶임, 🍌 미끄러짐, 💤 마취됨, 🪢 붙잡힘, 💰 매수됨)가 붙고, 등장 효과나 전술로 바뀐 점(공격력, 불, 보호막, 얻은 키워드…)이 카드 위에 뜬다.
- **선원 정보**: 고른 선원을 한 번 더 누르면 그 선원의 상태와 정보를 크게 본다.
- **튜토리얼**: 시작 화면의 🎓 튜토리얼로 실제 한 판을 두며 거의 모든 요소를 배운다.
- **규칙**: 탄력이 반격에도 적용된다. 냉기는 공격할 때만 얼리고 반격으로는 얼리지 않는다.
- **밸런스**: 모든 해적단 평균 승률 48~52%, 선원 카드 비용 점수 −2~+2 (견문색 AI, 해적단 쌍마다 2000판).

## 플레이

빌드 과정 없이 정적 파일만 있으면 됩니다. ES 모듈을 쓰기 때문에 `index.html`을 더블클릭하면 안 되고, 로컬 서버로 열어야 합니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

화면은 **가로가 기본**입니다. 폰에서는 게임을 시작하면 전체 화면 가로 모드로 바뀌고(지원하는 브라우저), 홈 화면에 추가하면 가로로 열립니다.

GitHub Pages: 저장소 **Settings → Pages → Branch: `main` / `(root)`** 로 켜면 바로 공개 주소가 생깁니다.

배포 전에는 `node tools/bump-version.js`를 실행해 `index.html`의 `?v=` 값과 `version.json`을 바꿔 주세요. 게임이 켜질 때 `version.json`을 캐시 없이 읽어 버전이 다르면 스스로 새로 열기 때문에, 홈 화면 앱도 예전 화면에 머물지 않습니다.

## 튜토리얼

시작 화면의 **🎓 튜토리얼**을 누르면 고무팔 해적단으로 쉬운 AI와 실제 한 판을 두면서, 배·바람·손패·카드 읽는 법·선원 정보 보기·리더 스킬·턴 종료·공격·연타·덱/일지/연출 버튼까지 말풍선으로 하나씩 알려 줍니다. 카드 내기, 턴 종료, 공격 같은 단계는 직접 해야 넘어갑니다. 튜토리얼 판은 전적에 남지 않습니다.

## AI 대전에서 상대 고르기

시작 화면의 **상대** 줄에서 **🎲 무작위**(기본)나 **🎯 직접 고르기**를 고릅니다. 직접 고르기를 켜면 내 해적단을 고른 뒤 상대 해적단을 한 번 더 고릅니다. 두 번째 단계에서 🎲 무작위를 누르면 내 해적단과 다른 해적단 중에서 무작위로 정해집니다.

**순서** 줄에서 **🎲 무작위**(기본), **⚔️ 선공**, **🪙 후공** 중 하나를 고릅니다. 후공은 카드 1장을 더 받고 `행운의 동전`을 받습니다.

## 친구와 대결 (한 폰에서)

시작 화면에서 **👥 친구와 대결**을 고르면 둘이서 폰 하나로 번갈아 둡니다.

- 1P가 먼저 진영을 고르고, 이어서 2P가 고릅니다(같은 진영도 가능). 목록 맨 앞의 **🎲 무작위**를 누르면 무작위로 정해집니다.
- 턴을 마치면 화면이 가려집니다. 폰을 넘긴 뒤 넘겨받은 사람이 **준비됐어요**를 누르면, 그 사람의 배가 아래로 오도록 화면이 뒤집힙니다.
- 시작 조건은 보통 난이도와 같습니다(선체 20, 후공은 카드 1장 + 행운의 동전).

## 규칙 요약

- **승리**: 보물 12개를 모으거나, 상대 배의 선체(20)를 0으로 만들면 승리
- **바람**: 매 턴 최대치가 1씩 늘고(최대 10) 다시 채워짐. 카드 비용으로 사용
- **선원**: 낸 다음 턴부터 공격. 적 배를 습격하면 선체 피해 + 보물 1개
- **키워드**: 돌격(즉시 공격) · 수호(먼저 공격받아야 함) · 약탈(습격 시 보물 +1) · 잠입(수호 무시) · 뻗기(양옆 적 중 무작위 하나에게도 1 피해) · 탄성(받는 피해 -1, 불 피해는 그대로) · 탄력(공격을 쉬면 팔을 당겨 공격력 강화, 반격에도 적용되고 공격하면 풀림) · 망령(한 번 되살아남, 붙은 불은 남고 되살아난 뒤에는 탄성을 뚫음) · 화염(공격해서 때린 적에게 불을 붙임, 반격으로는 안 붙음) · 성장(턴마다 강해짐) · 흡혈(준 피해만큼 선체 회복) · 연타(두 번 공격) · 보호막(첫 피해 무효) · 가시(공격한 선원에게 1 피해 더) · 안개(먼저 공격하기 전까지 대상 지정 불가) · 일섬(선원을 공격할 때 반격 피해 없음) · 순풍(다음 카드 비용 -1, 이어서 내면 최대 -2까지 쌓임) · 거래(보물 1개를 써서 추가 효과) · 잠항(낸 직후 상대 턴 동안 공격·대상 지정 불가) · 냉기(공격해서 피해를 준 적 선원을 얼려 다음 턴 공격 불가, 반격으로는 안 얼림) · 숙성(손패에 묵힐수록 비용 감소, 최대 -2) · 포식(가장 약한 아군을 잡아먹고 능력치 흡수) · 포자(쓰러지면 적 갑판에 포자를 심음. 포자는 두 턴 자리를 차지하다 두 번째 턴 끝에 주인 배에 1 피해를 주고 시들며, 한 갑판에 3개까지) · 입체기동(체력이 내 공격력 이상인 적 선원을 칠 때 +2) · 헌신(쓰러지면 가장 센 아군 공격력 +1) · 거인화(처음 쓰러지면 거인이 되어 일어남) · 등가교환(손패 1장을 버리고 추가 효과) · 재료(등가교환으로 버려지면 효과 발동)
- **리더 스킬 ✨**: 해적단마다 고유 스킬을 한 턴에 한 번, 바람을 써서 사용
- 후공은 카드 1장을 더 받고 `행운의 동전`(이번 턴 바람 +1)을 받음

## 난이도

배 체력(선체 20)과 시작 카드 수는 난이도와 상관없이 같습니다. 난이도는 AI 실력만 바꿉니다.

| 난이도 | AI |
|---|---|
| 🐣 쉬움 | 행동의 절반 이상을 실수 |
| 😽 보통 | 가끔 실수 |
| 🥵 어려움 | 실수 없음 |
| 👀 견문색 | 실수 없음 + 상대의 반격까지 내다봄 (밸런스 기준 AI) |

난이도 확인: `node tools/difficulty.js` (사람 실력을 흉내 낸 봇으로 승률 측정)

## 진영 (17개, 카드 253종, 덱은 해적단마다 30장: 고유 카드 25장 + 공용 카드 5장)

| 진영 | 스타일 |
|---|---|
| 🤸 고무팔 해적단 (주인공) | 고무팔을 쭉 뻗어 여러 적을 한꺼번에 치고, 팔을 당겨 모은 탄력으로 한 방을 노린다 |
| 🏴‍☠️ 붉은 돛 해적단 | 공격형. 돌격·약탈·잠입으로 보물을 빠르게 턴다 |
| 🐙 심해 함대 | 수비형. 수호 선원으로 버티고 거대한 함장으로 누른다 |
| 👻 유령선단 | 끈질긴형. 쓰러져도 망령으로 다시 일어나고, 쓰러질 때 유언을 남긴다 |
| 🔥 불꽃 요리단 | 지속 피해형. 적에게 불을 붙여 매 턴 태우고, 요리로 배를 고친다 |
| 🐒 정글 원숭이 무리 | 물량형. 원숭이 떼를 불러 갑판을 채우고 한꺼번에 강해진다 |
| ⚙️ 태엽 기계단 | 성장형. 약하게 시작하지만 턴마다 태엽이 감겨 점점 강해진다 |
| ⚔️ 떠돌이 검객단 | 선원 싸움형. 일섬으로 반격 없이 적 선원을 하나씩 베어 갑판을 정리한다 |
| 🧭 항해사 길드 | 연쇄형. 순풍 카드로 비용을 깎으며 한 턴에 여러 장을 몰아 내고, 낸 카드 수만큼 강해지는 카드로 마무리한다 |
| 🩺 잠수함 외과단 | 수술형. 잠항으로 숨어 있다가, 적 선원의 공격력과 체력을 뒤바꿔 무력하게 만든다 |
| 💰 황금 상인조합 | 거래형. 보물을 모으는 대신 써 버려서 선원을 강화하고 적을 매수한다 |
| ❄️ 아이스 에이지 | 빙결형. 냉기로 적 선원을 얼려 공격을 막고, 얼어붙은 적을 깨부순다 |
| 🍎 한국과수협회 | 숙성형. 크고 비싼 과일 카드를 손에 묵혀 익힌 뒤 싸게 낸다 |
| 🎢 에버랜드의 아이들 | 동물원형. 초식동물로 갑판을 지키고, 맹수가 작은 동료를 잡아먹어 거대해진다 |
| 🕊️ 조사병단 | 거인 사냥형. 입체기동으로 큰 적을 베고, 쓰러진 동료의 헌신을 이어받는다. 에렌과 아르민은 쓰러지면 거인이 되어 일어난다 |
| ⚗️ 국가 연금술사 | 등가교환형. 손패를 재료로 바쳐 카드를 강화하고, 연금술사와 부하들이 함께 싸운다 |
| 🍄 버섯 포자 군집 | 잠식형. 단단한 균사 선원으로 버티며 적 갑판에 포자를 심고, 포자가 적 배를 갉아먹는다 |

시작 화면의 **📖 카드 도감**에서 진영별 카드를 모두 볼 수 있습니다. 게임 중에는 **🃏 내 덱** 버튼으로 내 덱 카드의 원래 수치와 남은 장수를 볼 수 있고, 판 위 선원을 누르면 원래 수치와 지금 달라진 점이 함께 나옵니다.

시작 화면의 **📊 승률·상성**에는 탭이 두 개 있습니다.

- **🧑 내 전적**: AI 대전을 끝까지 한 판의 승패가 해적단별, 상대별로 쌓입니다. 난이도별로 걸러 볼 수 있고, 기록은 그 기기의 브라우저에만 저장됩니다. 친구와 대결과 중간에 그만둔 판은 기록하지 않습니다.
- **🤖 평균 승률 · 📏 표준편차 · 🧮 상성표**: 견문색 AI끼리 붙인 해적단 평균 승률, 상성 표준편차표(해적단마다 상대를 얼마나 타는지, 최악·최고 상성), 해적단 쌍별 상성표를 탭마다 보여 줍니다. `src/matchups.js`에 미리 계산해 둔 값이라, 밸런스를 바꾼 뒤에는 `node tools/matchups.js 1000 --write`로 다시 만들어야 합니다.

## 구조

```
index.html, style.css   화면
src/cards.js            카드·진영 데이터 (카드 추가는 여기서)
src/engine.js           규칙 엔진 (화면과 독립)
src/ai.js               AI 상대
src/fx.js               해적단별 공격 연출 (캔버스 입자)
src/notice.js           📢 공지사항 (새 버전을 낼 때 NOTES 맨 앞에 추가)
src/stats.js            📊 승률·상성 화면
src/matchups.js         AI 상성표 데이터 (tools/matchups.js --write 로 생성)
tools/simulate.js       AI끼리 대전시켜 밸런스 확인
tools/rush.js           배만 때리는 봇을 어려움 AI와 붙여 보물 러시가 너무 센지 확인
tools/cost-check.js     선원 카드의 비용 대비 능력치 점수(−2~+2) 점검
tools/card-list.js      모든 카드의 능력치·키워드·효과를 CARDS.md로 정리
tools/matchups.js       모든 해적단 쌍을 붙여 평균 승률과 쏠린 상성 확인 (--write: 게임 안 상성표 갱신)
```

밸런스 확인: `node tools/simulate.js 1000` · 러시 확인: `node tools/rush.js` · 전체 상성 확인: `node tools/matchups.js 1000` (평균 승률 48~52%, 상성 70% 이하가 목표)
