# 🤸 고무팔 해적단

팔이 고무처럼 늘어나는 해적들이 주인공인, 브라우저에서 AI와 겨루는 오리지널 카드게임입니다.

## 플레이

빌드 과정 없이 정적 파일만 있으면 됩니다. ES 모듈을 쓰기 때문에 `index.html`을 더블클릭하면 안 되고, 로컬 서버로 열어야 합니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

화면은 **가로가 기본**입니다. 폰에서는 게임을 시작하면 전체 화면 가로 모드로 바뀌고(지원하는 브라우저), 홈 화면에 추가하면 가로로 열립니다.

GitHub Pages: 저장소 **Settings → Pages → Branch: `main` / `(root)`** 로 켜면 바로 공개 주소가 생깁니다.

배포 전에는 `node tools/bump-version.js`를 실행해 `index.html`의 `?v=` 값과 `version.json`을 바꿔 주세요. 게임이 켜질 때 `version.json`을 캐시 없이 읽어 버전이 다르면 스스로 새로 열기 때문에, 홈 화면 앱도 예전 화면에 머물지 않습니다.

## AI 대전에서 상대 고르기

시작 화면의 **상대** 줄에서 **🎲 무작위**(기본)나 **🎯 직접 고르기**를 고릅니다. 직접 고르기를 켜면 내 해적단을 고른 뒤 상대 해적단을 한 번 더 고릅니다. 두 번째 단계에서 🎲 무작위를 누르면 내 해적단과 다른 해적단 중에서 무작위로 정해집니다.

## 친구와 대결 (한 폰에서)

시작 화면에서 **👥 친구와 대결**을 고르면 둘이서 폰 하나로 번갈아 둡니다.

- 1P가 먼저 진영을 고르고, 이어서 2P가 고릅니다(같은 진영도 가능). 목록 맨 앞의 **🎲 무작위**를 누르면 무작위로 정해집니다.
- 턴을 마치면 화면이 가려집니다. 폰을 넘긴 뒤 넘겨받은 사람이 **준비됐어요**를 누르면, 그 사람의 배가 아래로 오도록 화면이 뒤집힙니다.
- 시작 조건은 보통 난이도와 같습니다(선체 20, 후공은 카드 1장 + 행운의 동전).

## 규칙 요약

- **승리**: 보물 12개를 모으거나, 상대 배의 선체(20)를 0으로 만들면 승리
- **바람**: 매 턴 최대치가 1씩 늘고(최대 10) 다시 채워짐. 카드 비용으로 사용
- **선원**: 낸 다음 턴부터 공격. 적 배를 습격하면 선체 피해 + 보물 1개
- **키워드**: 돌격(즉시 공격) · 수호(먼저 공격받아야 함) · 약탈(습격 시 보물 +1) · 잠입(수호 무시) · 뻗기(양옆 적에게도 1 피해) · 탄성(받는 피해 -1) · 탄력(공격을 쉬면 팔을 당겨 다음 공격 강화) · 망령(한 번 되살아남) · 화염(때린 적에게 불을 붙임) · 성장(턴마다 강해짐) · 흡혈(준 피해만큼 선체 회복) · 연타(두 번 공격) · 보호막(첫 피해 무효) · 가시(공격한 선원에게 1 피해 더) · 안개(먼저 공격하기 전까지 대상 지정 불가) · 일섬(선원을 공격할 때 반격 피해 없음) · 순풍(다음 카드 비용 -1, 이어서 내면 최대 -2까지 쌓임) · 거래(보물 1개를 써서 추가 효과) · 잠항(낸 직후 상대 턴 동안 공격·대상 지정 불가) · 공명(전술 카드를 쓸 때마다 공격력 +1, 최대 2번) · 냉기(싸워서 피해를 입힌 적 선원을 얼려 다음 턴 공격 불가) · 숙성(손패에 묵힐수록 비용 감소, 최대 -2) · 포식(가장 약한 아군을 잡아먹고 능력치 흡수) · 피 냄새(다친 적 선원 공격 시 +2) · 포자(쓰러지면 적 갑판에 포자를 심음. 포자는 주인 배에 1 피해를 두 번 주고 시들며, 한 갑판에 3개까지)
- **선장 스킬 ✨**: 해적단마다 고유 스킬을 한 턴에 한 번, 바람을 써서 사용
- 후공은 카드 1장을 더 받고 `행운의 동전`(이번 턴 바람 +1)을 받음

## 난이도

| 난이도 | AI | 시작 조건 |
|---|---|---|
| 🐣 쉬움 | 행동의 절반 이상을 실수 | 내 선체 26 · 카드 +1, AI 선체 16 |
| ⚓ 보통 | 가끔 실수 | 같음 |
| 💀 어려움 | 실수 없음 | AI 선체 24 · 카드 +1 |

난이도 확인: `node tools/difficulty.js` (사람 실력을 흉내 낸 봇으로 승률 측정)

## 진영 (17개, 카드 245종, 덱은 해적단마다 30장: 고유 카드 25장 + 공용 카드 5장)

| 진영 | 스타일 |
|---|---|
| 🤸 고무팔 해적단 (주인공) | 고무팔을 쭉 뻗어 여러 적을 한꺼번에 치고, 팔을 당겨 모은 탄력으로 한 방을 노린다 |
| 🏴‍☠️ 붉은 돛 해적단 | 공격형. 돌격·약탈·잠입으로 보물을 빠르게 턴다 |
| 🐙 심해 함대 | 수비형. 수호 선원으로 버티고 거대한 함장으로 누른다 |
| 👻 유령선단 | 끈질긴형. 쓰러져도 망령으로 다시 일어나고, 쓰러질 때 유언을 남긴다 |
| 🔥 불꽃 요리단 | 지속 피해형. 적에게 불을 붙여 매 턴 태우고, 요리로 배를 고친다 |
| 🐒 정글 원숭이 무리 | 물량형. 원숭이 떼를 불러 갑판을 채우고 한꺼번에 강해진다 |
| ⚙️ 태엽 기계단 | 성장형. 약하게 시작하지만 턴마다 태엽이 감겨 점점 강해진다 |
| ⚔️ 떠돌이 검객단 | 선원 싸움형. 일섬으로 반격 없이 적 선원을 하나씩 베어 갑판을 정리한다 |
| 🧭 항해사 길드 | 연쇄형. 순풍 카드로 비용을 깎으며 한 턴에 여러 장을 몰아 내고, 낸 카드 수만큼 강해지는 카드로 마무리한다 |
| 🩺 잠수함 외과단 | 수술형. 잠항으로 숨어 있다가, 적 선원의 공격력과 체력을 뒤바꿔 무력하게 만든다 |
| 🌩️ 폭풍 주술단 | 주문형. 전술 카드를 쓸 때마다 공명하는 선원들이 점점 강해진다 |
| 💰 황금 상인조합 | 거래형. 보물을 모으는 대신 써 버려서 선원을 강화하고 적을 매수한다 |
| ❄️ 아이스 에이지 | 빙결형. 냉기로 적 선원을 얼려 공격을 막고, 얼어붙은 적을 깨부순다 |
| 🍎 한국과수협회 | 숙성형. 크고 비싼 과일 카드를 손에 묵혀 익힌 뒤 싸게 낸다 |
| 🎢 에버랜드의 아이들 | 동물원형. 초식동물로 갑판을 지키고, 맹수가 작은 동료를 잡아먹어 거대해진다 |
| 🦈 상어 사냥단 | 사냥형. 미끼로 상처를 내고, 피 냄새를 맡은 사냥꾼이 달려들어 끝낸다 |
| 🍄 버섯 포자 군집 | 잠식형. 단단한 균사 선원으로 버티며 적 갑판에 포자를 심고, 포자가 적 배를 갉아먹는다 |

시작 화면의 **📖 카드 도감**에서 진영별 카드를 모두 볼 수 있습니다. 게임 중에는 **🃏 내 덱** 버튼으로 내 덱 카드의 원래 수치와 남은 장수를 볼 수 있고, 판 위 선원을 누르면 원래 수치와 지금 달라진 점이 함께 나옵니다.

## 구조

```
index.html, style.css   화면
src/cards.js            카드·진영 데이터 (카드 추가는 여기서)
src/engine.js           규칙 엔진 (화면과 독립)
src/ai.js               AI 상대
tools/simulate.js       AI끼리 대전시켜 밸런스 확인
tools/rush.js           배만 때리는 봇을 어려움 AI와 붙여 보물 러시가 너무 센지 확인
tools/matchups.js       모든 해적단 쌍을 붙여 평균 승률과 쏠린 상성 확인
```

밸런스 확인: `node tools/simulate.js 1000` · 러시 확인: `node tools/rush.js` · 전체 상성 확인: `node tools/matchups.js 400` (평균 승률 48~52%, 상성 80% 미만이 목표)
